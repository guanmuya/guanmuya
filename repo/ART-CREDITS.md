## 动画与兼容性

- README 使用本仓库相对图片路径，无外部统计服务、追踪器或密钥。
- 桌面 1000 × 235，移动端 600 × 350。循环时长 4.8 秒，角色错峰跳跃。
- GIF 只在图片矩形范围内播放，不会在整个 GitHub 页面中移动，也不会响应键盘或鼠标。
- 为偏好减少动态效果的浏览器提供静态图；同时提供手动静态图链接。
- GitHub 会清理 README 中的脚本与样式：[GitHub 官方渲染说明](https://github.com/github/markup)。相对图片说明见 [GitHub Docs](https://docs.github.com/en/get-started/writing-on-github/getting-started-with-writing-and-formatting-on-github/basic-writing-and-formatting-syntax#images)。
